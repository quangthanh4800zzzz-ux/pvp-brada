# Roadmap

| Phase | Scope | State |
|---|---|---|
| 1 — Core Engine | Game loop, rendering, input, settings, physics, camera, scenes | ✅ Done (see status doc) |
| 2 — Combat Engine | Attacks, hitboxes, damage, guard, combo, energy, rounds | ✅ Done |
| 3 — Character System | 20-character roster, skill 1–4 + ultimates, passives wired into sim, character select | ⏳ Next |
| 4 — Animation | Full animation set per character, frame events (sounds/particles/hitbox toggles) | ⏳ Next |
| 5 — Map System | 10 distinct maps, hazards, destructibles, camera rules per map | Planned |
| 6 — AI | Bot FSM, 5 difficulties, survival/boss/team modes | Planned |
| 7 — Multiplayer | ws server, rooms, matchmaking, authoritative sim, prediction/reconciliation | Planned |
| 8 — Training | Combat Lab sub-labs (combo/aim/reflex/movement/defense/skill/physics sandbox) | Planned |
| 9 — UI & Settings | Character select, pause menu, full settings pages | Planned |
| 10 — Polish | Audio, VFX depth, balancing, performance, docs, production build | Planned |

Feature requests beyond the plan (grab throws, wall bounce, projectiles, summons, LAN QR codes, spectator mode, accounts/DB) are tracked in IMPLEMENTATION-STATUS.md as Not Implemented until they land.
